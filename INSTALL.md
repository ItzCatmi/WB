# 📦 Как скачать и запустить проект

## Способ 1: Скачать все файлы

Скопируйте все файлы проекта в одну папку:

```
wildberries/
├── README.md
├── index.html
├── install.bat          ← для Windows
├── install.sh           ← для Linux/Mac
├── package.json
├── package-lock.json
├── requirements.txt
├── server.py
├── src/
│   ├── App.tsx
│   ├── index.css
│   ├── main.tsx
│   ├── store.ts
│   └── types.ts
├── start.bat            ← для Windows
├── start.sh             ← для Linux/Mac
├── tsconfig.json
└── vite.config.js
```

## Способ 2: Скачать через Git (если проект на GitHub)

```bash
git clone <url-репозитория>
cd wildberries
```

## 🚀 Запуск

### Windows:
1. **Первый раз**: дважды кликните `install.bat`
2. **Каждый раз**: дважды кликните `start.bat`

### Linux/Mac:
```bash
# Первый раз
chmod +x install.sh start.sh
./install.sh

# Каждый раз
./start.sh
```

## ✅ Что должно произойти

1. Установятся все зависимости (Python + Node.js)
2. Соберётся фронтенд
3. Запустится сервер на порту 5000
4. В консоли появится IP-адрес для доступа

## 📱 Доступ к приложению

### С телефона (в той же WiFi):
- Откройте браузер
- Перейдите по адресу из консоли (например: `http://192.168.1.100:5000`)
- Это мобильная версия для покупок

### С ПК:
- Откройте браузер
- Перейдите по адресу из консоли или `http://localhost:5000`
- Это панель пункта выдачи

### Панель управления:
- Нажмите **F6** на клавиатуре
- Откроется панель для создания/редактирования товаров

## ⚠️ Требования

- **Python 3.8+** — [скачать](https://www.python.org/downloads/)
- **Node.js 16+** — [скачать](https://nodejs.org/)

## 🔧 Если что-то не работает

### "pip не найден"
Установите Python и добавьте в PATH

### "npm не найдено"
Установите Node.js

### "Порт 5000 занят"
Откройте `server.py`, найдите `port = 5000` и измените на другой порт

### "Не могу подключиться с телефона"
- Проверьте что телефон и ПК в одной WiFi сети
- Проверьте firewall (может блокировать порт 5000)
- Попробуйте временно отключить firewall
