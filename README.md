# 🛒 Wildberries - Пункт выдачи заказов

Клон Wildberries с разделением интерфейсов:
- **📱 Телефон** (в локальной сети) — мобильная версия для покупок
- **🖥️ ПК** (в локальной сети) — панель пункта выдачи заказов
- **⚙️ F6** — панель управления товарами

## 🚀 Быстрый старт

### Windows:
1. Дважды кликните `install.bat` — установит все зависимости
2. Дважды кликните `start.bat` — запустит сервер

### Linux/Mac:
```bash
chmod +x install.sh start.sh
./install.sh
./start.sh
```

## 📋 Что нужно установить заранее

- **Python 3.8+** — [скачать](https://www.python.org/downloads/)
- **Node.js 16+** — [скачать](https://nodejs.org/)

## 🌐 Как пользоваться

После запуска сервер покажет IP-адрес в консоли:

```
============================================================
  🛒 Wildberries - Пункт выдачи заказов
============================================================

  📱 Мобильная версия (покупки):
     http://192.168.1.100:5000

  🖥️  Десктопная версия (ПВЗ):
     http://192.168.1.100:5000

  💻 Локально:
     http://localhost:5000

  ⚙️  Панель управления товарами:
     Нажмите F6 в браузере
============================================================
```

### С телефона (в той же WiFi сети):
1. Откройте браузер на телефоне
2. Перейдите по адресу `http://192.168.x.x:5000` (IP из консоли)
3. Покупайте товары, оформляйте заказы

### С ПК:
1. Откройте браузер на ПК
2. Перейдите по адресу `http://192.168.x.x:5000` или `http://localhost:5000`
3. Управляйте пунктом выдачи, выдавайте заказы

### Панель управления (F6):
Нажмите **F6** на любом устройстве чтобы:
- Создавать товары с фотографиями
- Редактировать существующие товары
- Удалять товары
- Управлять заказами

## 💾 Хранение данных

Все данные хранятся на сервере в папке `data/`:
- Товары, заказы, корзины — JSON файлы
- Фотографии — в папке `data/uploads/`
- Корзины изолированы по device_id (каждое устройство имеет свою корзину)

## 🛠 Технологии

- **Backend**: Python 3 + Flask
- **Frontend**: React 18 + TypeScript + Tailwind CSS
- **Build**: Vite
- **Storage**: JSON файлы на сервере
- **Upload**: Локальная файловая система

## 📝 API Endpoints

```
GET    /api/products          # Получить все товары
POST   /api/products          # Создать товар
PUT    /api/products/:id      # Обновить товар
DELETE /api/products/:id      # Удалить товар

GET    /api/orders            # Получить все заказы
POST   /api/orders            # Создать заказ
PUT    /api/orders/:id/status # Изменить статус заказа

GET    /api/cart/:device_id   # Получить корзину устройства
POST   /api/cart/:device_id   # Сохранить корзину
DELETE /api/cart/:device_id   # Очистить корзину

POST   /api/upload            # Загрузить изображения
GET    /api/uploads/:filename # Получить загруженный файл
```

## ❓ Проблемы и решения

### "Команда pip не найдена"
Установите Python и добавьте его в PATH

### "Команда npm не найдена"
Установите Node.js

### "Порт 5000 занят"
Откройте `server.py` и измените `port = 5000` на другой порт

### "Не могу подключиться с телефона"
- Убедитесь что телефон и ПК в одной WiFi сети
- Проверьте что firewall не блокирует порт 5000
- Попробуйте отключить firewall на время

### "Данные не сохраняются"
Проверьте что у процесса есть права на запись в папку `data/`

## 📞 Поддержка

3. Фронтенд собран (папка `dist/` существует)
