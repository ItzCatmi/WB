# 🛒 Wildberries - Пункт выдачи заказов

Клон Wildberries с разделением интерфейсов:
- **📱 Телефон** (в локальной сети) — мобильная версия для покупок
- **🖥️ ПК** (в локальной сети) — панель пункта выдачи заказов
- **⚙️ F6** — панель управления товарами (создание, редактирование, удаление)

## 🚀 Запуск

### 1. Установите Python зависимости:
```bash
pip install -r requirements.txt
```

### 2. Соберите фронтенд (если нужно пересобрать):
```bash
npm install
npm run build
```

### 3. Запустите сервер:
```bash
python server.py
```

### 4. Откройте в браузере:
Сервер покажет IP-адрес в консоли:
- **С телефона** (в той же WiFi сети): `http://192.168.x.x:5000` — мобильная версия для покупок
- **С ПК**: `http://192.168.x.x:5000` — панель пункта выдачи
- **Локально**: `http://localhost:5000`

## 📋 Возможности

### Мобильная версия (телефон):
- Каталог товаров с поиском и фильтрацией по категориям
- Страница товара с выбором размера/цвета
- Корзина с изменением количества
- Оформление заказа с указанием имени и телефона
- Получение кода для выдачи

### Десктопная версия (ПВЗ):
- Статистика заказов (активные, готовые, выданные)
- Список всех заказов со статусами
- Выдача по коду (ввод 6-значного кода)
- Быстрая выдача готовых заказов
- Изменение статусов заказов

### Панель управления (F6):
- Создание товаров с загрузкой фотографий
- Редактирование существующих товаров
- Удаление товаров
- Цены: без скидки и со скидкой
- Размеры и цвета
- Управление заказами

## 📁 Структура данных

Все данные хранятся на сервере в папке `data/`:
- `data/products.json` — товары
- `data/orders.json` — заказы
- `data/cart_<device_id>.json` — корзины устройств
- `data/uploads/` — загруженные изображения

## 🔧 Технологии

- **Backend**: Python + Flask
- **Frontend**: React + TypeScript + Tailwind CSS
- **Storage**: JSON файлы на сервере
- **Upload**: Локальная файловая система
